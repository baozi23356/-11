# 抖音视频下载拓展使用说明

## 简介
本拓展是一个用于下载抖音视频的工具，支持从抖音 App 或网页版直接获取视频链接并下载到本地。用户可以通过简单的操作，快速保存喜欢的视频内容。

## 功能特点
1. **一键下载**：支持通过视频链接或分享内容快速下载视频。
2. **高清画质**：默认下载最高画质的视频文件。
3. **多平台支持**：兼容抖音 App 和网页版。
4. **简单易用**：界面简洁，操作方便。

## 安装方法
1. 下载拓展文件（如 `.crx` 或 `.zip`）。
2. 打开浏览器的扩展程序管理页面（如 Chrome 的 `chrome://extensions/`）。
3. 启用“开发者模式”。
4. 将下载的拓展文件拖拽到页面中完成安装。

## 使用步骤
1. 打开抖音 App 或网页版，找到需要下载的视频。
2. 点击视频右下角的“分享”按钮，复制视频链接。
3. 打开本拓展，粘贴链接并点击“下载”按钮。
4. 等待下载完成，视频将保存到本地默认文件夹。

## 注意事项
1. 请确保下载的视频仅用于个人学习或娱乐，禁止用于商业用途。
2. 下载过程中请保持网络连接稳定。
3. 如果遇到下载失败，请检查链接是否正确或尝试重新下载。

## 常见问题
### 1. 下载的视频无法播放怎么办？
- 确保本地播放器支持视频格式（如 MP4）。
- 检查视频文件是否完整下载。

### 2. 拓展无法安装怎么办？
- 确认浏览器版本是否支持拓展功能。
- 检查拓展文件是否损坏。

### 3. 下载速度慢怎么办？
- 检查网络连接是否正常。
- 尝试更换网络环境。
