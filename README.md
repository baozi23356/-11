# 抖音视频下载助手 (Edge浏览器扩展)

## 🚀 功能介绍
这是一个简单易用的Edge浏览器扩展，可以帮助用户下载抖音视频。

### ✨ 主要功能
- 自动检测抖音视频页面
- 一键下载无水印视频
- 支持单个视频下载
- 友好的用户界面

## 📦 安装说明
### 方法一：Edge扩展商店（开发中）
即将上架Edge扩展商店

### 方法二：手动安装
1. 下载本项目代码
2. 打开Edge浏览器，进入扩展管理页面 (edge://extensions/)
3. 开启"开发人员模式"
4. 点击"加载解压缩的扩展"
5. 选择本项目文件夹即可完成安装

## 🛠 技术架构
- manifest.json: 扩展配置文件
- popup.html: 扩展弹窗界面
- content.js: 视频检测和下载逻辑
- background.js: 后台服务
